# 04-06: Intercepting Traffic with Burp Suite

## Overview
Burp Suite is an integrated platform for performing security testing of web applications. Its proxy tool allows researchers to intercept and modify HTTP requests between the browser and the server.

## Core Components
- **Proxy**: Intercepts traffic.
- **Repeater**: Manually modifies and reissues individual HTTP requests.
- **Intruder**: Performs automated customized attacks (e.g., brute forcing).
- **Decoder**: Transforms encoded data into its canonical form.
