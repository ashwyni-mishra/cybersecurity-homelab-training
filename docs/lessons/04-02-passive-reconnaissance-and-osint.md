# 04-02: Passive Reconnaissance and OSINT

## Overview
Passive reconnaissance involves gathering information about a target without directly interacting with their infrastructure. Open Source Intelligence (OSINT) is a key component.

## Techniques
- **Whois Lookups**: Identifying domain registration details.
- **DNS Enumeration**: Using passive sources like VirusTotal or SecurityTrails.
- **Search Engines**: Using Google Dorks to find sensitive documents or exposed interfaces.
- **Social Media**: Analyzing LinkedIn or GitHub for employee details and technology stacks.
